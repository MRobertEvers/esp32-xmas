Set up your display

Pick the Wi-Fi network the display should join.

Strongest first, as the display heard them before starting its own network. Forgotten it? On iPhone: Settings → Wi-Fi → ⓘ next to your network → Password. On Android: Settings → Wi-Fi → your network → Share. Then paste it here. Leave blank if your server announces itself — the display will find it. You can set this later either way.

Joining… the display restarts, so this page may close on its own. That is normal.
