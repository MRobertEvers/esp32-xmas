# Archived post-v2 attempts

Iron Man revisions v3–v10, their export scripts, instructions, previews, validation reports,
STLs, and the v6 reference artwork were moved here at the user’s request. Nothing was deleted.

The original relative layout is retained. Run each export script from this folder as before.
`xmas_orn_case.scad` forwards to the [shared core](../xmas_orn_case.scad), so the archived
sources can still be opened and rendered. For core measurements and assumptions, see the
[main enclosure instructions](../README.md).

[manifest.json](manifest.json) records every moved file’s original path, archived path and
SHA-256 hash. Archived files were preserved byte for byte; validation reports describe their
original exports. Version 1 and version 2 remain in the parent folder.
